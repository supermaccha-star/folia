# TRPG募集ボット

`/募集` で募集メッセージを投稿し、ボタンで参加・キャンセル・締切ができます。

## 機能
- 参加 / キャンセル / 締切(再開)ボタン
- 定員を超えるとキャンセル待ちに自動登録、空きが出たら繰り上げて通知
- 伝助・ココフォリアのURLを募集に添付
- 締切・再開はGMまたは「サーバー管理」権限を持つ人のみ
- 再起動後もボタンが動作(データは `recruits.json` に保存)

## セットアップ
1. Discord Developer Portal でアプリを作成し、Botのトークンを取得
2. OAuth2 の招待URLで `bot` と `applications.commands` を選び、権限は「チャンネルを見る」「メッセージを送信」「埋め込みリンク」を付けてサーバーに招待
3. ホスティング先に `main.py` と `requirements.txt` を置く
4. 環境変数を設定
   - `DISCORD_TOKEN` : Botのトークン(必須)
   - `GUILD_ID` : サーバーID(任意。設定するとコマンドがすぐ反映される)
5. `pip install -r requirements.txt` のあと `python main.py`

## 注意
- 無料ホスティングは再起動でファイルが消える場合があります。`recruits.json` を保持できる(永続ディスクがある)サービスを選んでください。
- トークンはコードに直書きせず、必ず環境変数かシークレット機能で渡してください。
- ココフォリアのURLは募集メッセージを見られる全員に表示されます。
